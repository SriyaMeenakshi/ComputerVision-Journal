# 👁️ Computer Vision Journal

A hands-on learning journal documenting my journey into Computer Vision.

The goal of this repository is to learn Computer Vision from the fundamentals by
understanding concepts, implementing them in Python, experimenting with images,
and gradually building real-world projects.

---

## 🎯 Goal

Learn Computer Vision from the ground up and build the ability to:

- Understand images as numerical data
- Work with OpenCV and NumPy
- Process and manipulate images
- Understand image transformations
- Perform image analysis
- Learn classical Computer Vision techniques
- Progress towards Deep Learning and real-world CV projects
